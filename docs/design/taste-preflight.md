# Taste 预检：应用壳与设计系统

## 设计解读

这是面向个人日常记账的原生 macOS 应用壳，视觉语言克制、可信并保留纸张触感。实现采用 SwiftUI 原生组件和语义令牌，不模拟网页营销页，也不扩展到真实记账流程。

- `DESIGN_VARIANCE: 5`：保留原生侧边栏秩序，通过品牌色与非居中内容建立辨识度。
- `MOTION_INTENSITY: 3`：只有目的地切换反馈；系统“减少动态效果”开启后归零。
- `VISUAL_DENSITY: 5`：适合桌面日常工具，不堆叠装饰卡片。

## 系统决策

- 一套组件和信息层级，系统、浅色、深色仅切换语义颜色令牌。
- 浅色使用暖纸、森林绿、陶土色；深色使用石墨、苔藓和低饱和荧光绿。
- 字体只使用 macOS 系统、系统衬线和系统圆角设计，不捆绑字体。
- 图标统一为 Lucide 0.468.0、2 pt 线宽的固定 SVG。无 emoji、位图或 SF Symbols。
- 一级导航为记账、AI 助手、日历、统计、设置。设置使用齿轮图标，侧边栏文案不显示快捷键。
- 圆角由系统控件统一管理；占位目的地不制造额外卡片层级。
