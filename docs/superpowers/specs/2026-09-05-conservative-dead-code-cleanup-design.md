# V1.1.0 保守死代码清理设计

## 目标

删除全仓库中经引用搜索、编译器和现有测试可以证明未使用的代码，不改变 V1.1.0 的 UI、数据流、交互、本地化或持久化行为。

## 范围

- 删除从未实例化的 `DestinationPlaceholder` 及其专用 subtitle 路径。
- 删除无调用的旧排序入口，保留当前拖拽排序。
- 删除仅原样返回输入的辅助方法、未使用参数、未使用格式化重载和未使用主题令牌。
- 删除只服务于上述死代码的测试与本地化键。
- 仅在确认 `standalone` 设置分支无任何构建目标或入口调用时删除该分支。

## 不在范围

- 不精简字体、动效、AI 数据结构或当前拖拽手势。
- 不修改已确认的 UI 尺寸、对齐、渐隐、菜单语言或导航行为。
- 不顺手处理安全、迁移、AI 上下文和导入性能问题。
- 不新增依赖，不打包，不上传 GitHub。

## 验证

1. 每组删除前先用测试或源码契约产生预期失败，再做最小删除。
2. 运行相关单元测试、`xcodebuild analyze`、Debug 构建。
3. 只打开当前 V1.1.0 Debug App 供用户肉眼验收。

## 成功标准

- 生产构建和静态分析通过。
- 与被删代码相关的过期测试同步移除，其余测试不产生新失败。
- 产品中不出现新的 UI 或功能差异。
