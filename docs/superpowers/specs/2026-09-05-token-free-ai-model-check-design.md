# AI 模型零 Token 检测设计

## 目标

AI 设置页继续自动检测所有模型，但检测过程不得发送生成请求或消耗生成 Token。检测结果缓存 10 分钟，并提供一个“检测模型”按钮立即重新检测全部预设。

## 行为

- 检测使用预设 Base URL 下的 `GET /models`，携带现有 Bearer API Key。
- HTTP 成功且返回的模型列表包含预设的模型 ID 时，状态为已连接；其余情况为未连接。
- 不支持 `/models`、缺少必要配置、网络错误或响应异常时直接判定失败，不回退到文本生成请求。
- 进入 AI 设置页时，仅检测从未检测或上次检测已超过 10 分钟的预设。
- 每个预设保存一个可选的最近检测时间；旧设置缺少该字段时视为从未检测。
- “检测模型”按钮忽略缓存并立即并行检测全部预设；检测进行时按钮不可重复触发。
- 模型编辑器内已有的连接测试复用同一套 `/models` 检测，不再发送“Connection test”对话。
- 只保留现有单一连接状态，不新增状态层级。

## 数据与兼容性

`AIModelPreset` 增加可选检测时间字段并继续使用兼容旧数据的 Codable 解码。修改模型配置后清空检测时间，避免沿用旧配置的缓存结果。API Key 仍只保存在 macOS Keychain。

## 错误与日常使用

检测失败只更新设置页的连接状态，不影响保存预设，也不改变正常 AI 记账和分析请求。第三方服务若不提供 OpenAI 兼容的 `/models` 接口，会显示未连接，但软件不会为兼容它而自动消耗 Token。

## 验证

- 请求测试确认方法为 GET、路径为 `/models`、无请求体。
- 测试模型存在、模型缺失、HTTP 失败和异常响应。
- 测试 10 分钟内跳过自动检测、过期后重检、手动检测绕过缓存。
- 运行完整单元测试、静态分析和 Debug 构建。
