# AI 模型最小生成检测设计

## 目标

AI 设置页使用真实但最小的生成请求检测所有模型。检测结果缓存 10 分钟，并提供一个“检测模型”按钮立即重新检测全部预设。

## 行为

- 检测直接使用预设的协议、Base URL、API Key 和模型名称发起非流式请求。
- 请求输入只有 `1`，不加入系统提示、日期、账目或其他上下文。
- Chat Completions 使用 `max_tokens: 1`；Responses 使用 `max_output_tokens: 1`。
- HTTP 成功且返回合法 JSON 对象时状态为已连接；配置错误、鉴权失败、网络错误或响应异常时为未连接。
- 进入 AI 设置页时，仅检测从未检测或上次检测已超过 10 分钟的预设。
- 每个预设保存一个可选的最近检测时间；旧设置缺少该字段时视为从未检测。
- “检测模型”按钮忽略缓存并立即并行检测全部预设；检测进行时按钮不可重复触发。
- 模型编辑器内已有的连接测试复用同一套最小生成检测。
- 只保留现有单一连接状态，不新增状态层级。

## 数据与兼容性

`AIModelPreset` 增加可选检测时间字段并继续使用兼容旧数据的 Codable 解码。修改模型配置后清空检测时间，避免沿用旧配置的缓存结果。API Key 仍只保存在 macOS Keychain。

## 错误与日常使用

检测失败只更新设置页的连接状态，不影响保存预设，也不改变正常 AI 记账和分析请求。每次实际检测会产生极少量输入 Token 和最多 1 个输出 Token；10 分钟缓存避免反复进入设置页造成重复消耗。

## 验证

- 请求测试确认 Chat Completions 与 Responses 均调用真实生成端点、只输入 `1` 且最多输出 1 Token。
- 测试 HTTP 失败和异常响应。
- 测试 10 分钟内跳过自动检测、过期后重检、手动检测绕过缓存。
- 运行完整单元测试、静态分析和 Debug 构建。
