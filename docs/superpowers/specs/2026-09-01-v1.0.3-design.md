# V1.0.3 设计规格

## 范围

以用户提供的《V1.0.3 更新清单（修订版）》为唯一功能范围，分为分类与账目、AI、外观与导航三个独立实现域；共享导航、本地化、工程配置和构建脚本由主 Agent 集中修改。

## 架构边界

- A：分类完整性规则、账目删除确认、日历操作、历史数据与本地搜索。
- B：本地日期序列化、AI 草稿容错、全量分析、编辑器输入法语义、模型预设与连接状态。
- C：主题即时切换根因、全局字体比例、窗口布局和导航呈现；导航枚举改动只提交变更清单。
- 主 Agent：共享文件、版本号、最终集成、全量测试、人工验收、arm64 发布物。

## 数据与交互约束

分类删除必须迁移同类型账目到受保护的“其他”；删除统一二次确认。AI 日期仅使用用户本地 `yyyy-MM-dd`。模型状态只由显式连接测试更新。字体比例为 80%–140%、步进 5%，立即生效。历史搜索完全本地执行。

## 验证

每个域先建立失败测试再最小实现；主 Agent 复核 diff 并按 A→B→C 集成。最终执行全部单元/UI 测试、Debug 与 Release 构建，启动 App 进行肉眼验收，验证 arm64、DMG 挂载和 SHA-256。
