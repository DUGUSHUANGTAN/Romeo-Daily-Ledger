# V1.0.3 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在本地完成 V1.0.3 修订清单并产出可验证的 arm64 DMG。

**架构：** 三个隔离 worktree 分别实现 A/B/C，主分支严格按 A→B→C cherry-pick。共享导航、本地化与工程配置由主 Agent 独占，避免并行冲突。

**技术栈：** Swift 6、SwiftUI、SwiftData、XCTest/XCUITest、XcodeGen、macOS、Git worktree。
